# SunTrack Simulator

SunTrack is an interactive solar energy simulator
based on physics and numerical computation.

## Features
- Solar panel power calculation
- Solar irradiance analysis
- Panel tilt optimization
- Daily energy simulation
- Shading and temperature analysis
- Scenario comparison
- 3D visualization
- PDF report generation

## Technology
- Python
- Streamlit
- NumPy
- Plotly
- ReportLab

## How to Run

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.py
